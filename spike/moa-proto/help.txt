
  moa keys                                              (q closes this)

  Ctrl-a          moa's keys, from anywhere; the status line lists them while
                  it's held. It's the only key you need to remember.
  Ctrl-a ←↑↓→     move to the pane that way (or h j k l); tap more arrows
                  right after to keep moving
  Ctrl-a /        find a session: type part of its name, Enter jumps (or s)
  Ctrl-a c t p g  console · sessions tree · big picture · agent spot
  Ctrl-a z        zoom this pane to the whole window (again to unzoom)
  Ctrl-a Space    the full menu (or Ctrl-a twice): new session, layouts, repair
  Ctrl-a a        a real Ctrl-a for the app (start of line)

  In the sessions tree
    j / k         move            Enter   open (into the cockpit's agent spot)
    n             new session     +       new group
    m             move to group   r       rename (session or group)
    a             archive         x       close          D   delete empty group

  In the console
    type anything to talk to moa; /help lists the instant commands
    /layout NAME  switch layout   /focus Q   show a session   /open PATH title

  Layouts         cockpit (tree · console · big picture)     Ctrl-a 1
                  focus   (tree and big picture · live agent · console)   Ctrl-a 2
                  classic (console · big picture and tree)   Ctrl-a 3
                  triage  (status · console · big picture)   Ctrl-a 4
                  Ask moa to change one: "make the tree narrower".

  Agent states    ⚠ needs you (a permission prompt)   ? asked you something
  (status panel,  ✓ done since you last looked        ◐ working   ● idle
  status line)    The status line names only the ⚠ and ? ones; the rest are counts.

  Moving around   Ctrl-a / finds any session; in an agent's own window,
                  Ctrl-a m comes back to moa. Clicking a pane works too.
